Create all the zombie characters listed below for a first-person zombie shooter in the style of Call of Duty Black Ops Zombies.
There are three maps: a 1938 island prison, a 1961 steel foundry, and a 1963 Alcatraz-style island prison. Four zombie types per map.

RULES FOR EVERY MODEL
- Three zombies already exist. Do not recreate them: match each existing zombie to the most similar type in the list, rename it with that file name, and create only the missing types.
- If an existing zombie is only missing the rig, add only the rig, without regenerating the model.
- No animations: the game animates the skeleton by itself. Only the rig is needed (bones and skin weights, humanoid, Mixamo-compatible bone names, same skeleton for all zombies).
- Maximum 15000 faces per character. Triangle topology. Symmetry on.
- Realistic style, PBR textures, 1024 px textures, horror, rotten skin, glowing orange eyes unless stated otherwise.
- Same base body for all: adult human, 1.8 m tall, realistic proportions, full body, T-pose with arms straight out to the sides, standing straight, feet on the ground.
- Nothing hanging far from the body (it would rig badly). No weapons in the hands.
- No readable text, letters or numbers on clothes or badges: use plain patches instead.
- Export .glb with the given file name.

NEGATIVE: text, letters, words, numbers, logo, watermark, base, pedestal, ground plane, multiple characters, weapon, cartoon, chibi, big head, toy, low quality
