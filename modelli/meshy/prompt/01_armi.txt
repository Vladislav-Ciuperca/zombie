Create all the weapon 3D models listed below for a first-person zombie shooter in the style of Call of Duty Black Ops Zombies.

RULES FOR EVERY MODEL
- Do not recreate a model that already exists (same file name or an equivalent weapon already made). Skip it.
- If an existing model is only missing its moving parts, do only that: split those parts and rename them, without regenerating the model.
- Maximum 3000 faces per weapon. Triangle topology.
- Realistic style, PBR textures, 2048 px textures, period weapons from the 1930s to the 1960s, worn and used: scratched blued steel, chipped wood, rust spots.
- One weapon per model, no hands, no stand, no ground, centered, side view.
- No readable text, letters, logos or serial numbers anywhere.
- Real-world size given for each weapon. Export .glb with the given file name.
- Moving parts used by the reload animation must be separate objects with these exact names; everything else is one object named "corpo":
  mag = magazine, drum or ammo box; bolt = bolt with its handle; slide = charging handle or slide; pump = pump grip;
  brl = everything in front of the hinge (barrels and fore-end) on break-action weapons; cyl = revolver cylinder;
  lid = top cover over the ammo belt; cell = replaceable energy cell or canister.

NEGATIVE: text, letters, words, logo, watermark, serial number, hands, base, pedestal, ground plane, multiple objects, cartoon, toy, low quality
