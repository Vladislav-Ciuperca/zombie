Create all the game machines listed below for a first-person zombie shooter in the style of Call of Duty Black Ops Zombies.

RULES FOR EVERY MODEL
- Do not recreate a model that already exists. Skip it.
- If an existing model is only missing its moving part, do only that: split the part and rename it, without regenerating the model.
- Maximum 5000 faces per model (vending machines, crate, forge, power switch), maximum 1500 faces for small items (plank, trap lever, recorder).
- Triangle topology. Realistic style, PBR textures, 1024 px textures, worn, dirty and weathered, 1930s to 1960s look.
- One object per model, centered, no ground.
- No readable text, letters or numbers anywhere: the vending machines show only a big emblem picture, the game adds the names later.
- Moving parts must be separate objects with these exact names; everything else is one object named "corpo":
  coperchio = lid of the weapon crate; leva = lever of the power switch and of the trap lever box.
- Real-world size given for each model. Export .glb with the given file name.

NEGATIVE: text, letters, words, numbers, logo, watermark, base, pedestal, ground plane, multiple objects, cartoon, toy, low quality
